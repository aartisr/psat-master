Deployment & Environment Variables Guide

Welcome to the developer configuration manual. To support an offline-first experience with secure, server-side AI integrations (powered by Gemini), the PSAT Master suite utilizes a modern full-stack architecture. Learn how to configure your environment variables and deploy the application to Vercel in seconds.

🔐 Environment Variables Overview

Because the application makes server-side AI calls (to prevent exposing your Gemini API Keys to the browser), these values must be configured inside your Vercel Dashboard under Settings > Environment Variables.

GEMINI_API_KEY

Required (Secret)
The API token from Google AI Studio. Used for generating Socratic hints, AI Tutor responses, and deep breakdown paths.

APP_URL

Required
The absolute web URL where your application is hosted (e.g., https://psat-master.vercel.app) to map API endpoints.

🔥 Optional Firebase Configuration

PSAT Master operates entirely local-first out of the box using encrypted LocalStorage. If you want to configure optional persistent user accounts, diagnostic syncs, or community telemetry metrics, you can optionally connect a custom Firebase Firestore database by setting these variables:

VITE_FIREBASE_API_KEY

Your public Firebase application API key.

VITE_FIREBASE_PROJECT_ID

The unique project identifier of your Firestore instance.

VITE_FIREBASE_APP_ID

The registered application identifier of your Firebase web app.

VITE_FIREBASE_AUTH_DOMAIN

Authentication callback domain (e.g., project-id.firebaseapp.com).

🚀 Step-by-Step Vercel Setup Guide

Deploying PSAT Master is streamlined and takes fewer than 2 minutes. Follow these simple steps:

Step 1: Import Repository
Log into your Vercel Dashboard, click Add New > Project, and import the psat-master repository.

Step 2: Configure Environment Variables
Go to the Environment Variables tab and add your keys: 

GEMINI_API_KEY = "your_google_api_key_here"
APP_URL = "https://your-app-subdomain.vercel.app"

Step 3: Keep Default Build Command
The build settings are pre-configured inside the repository. Vercel automatically detects Vite and Node.js to bundle and serve your production instance.

Step 4: Deploy
Click Deploy. Vercel will build the static assets, compile the server-side API proxy handlers, and deploy your site to a globally distributed edge network!
